## Funcionalidades

- Multiplicação: `5 × 4 = 20`
- Divisão: `20 ÷ 5 = 4`
- Soma e subtração
- Tratamento de divisão por zero

A versão online está em `docs/index.html` e funciona no navegador com JavaScript. A versão em Python/Flask está disponível no mesmo repositório.

## Executar a versão Flask localmente

Execute os comandos **separadamente** no terminal da pasta do projeto:

```bash
pip install -r requirements.txt
python app.py
```

Depois, abra http://127.0.0.1:5000 no computador que está executando o Flask.
