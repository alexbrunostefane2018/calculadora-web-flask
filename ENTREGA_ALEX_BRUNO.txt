OPERAÇÕES IMPLEMENTADAS:
- Multiplicação
- Divisão (com tratamento para divisão por zero)
- Soma
- Subtração

COMO EXECUTAR A VERSÃO FLASK LOCALMENTE:
1. pip install -r requirements.txt
2. python app.py
3. Abrir http://127.0.0.1:5000
