OPERAÇÕES IMPLEMENTADAS:
- Multiplicação (exemplo: 5 x 4 = 20)
- Divisão (exemplo: 20 / 5 = 4)
- Soma
- Subtração
- Tratamento de divisão por zero

CONFIRMAÇÃO DE FUNCIONAMENTO:
O GitHub Pages exibe a publicação do site como ativa.
O responsável pelo projeto confirmou que abriu a calculadora pelo navegador
e testou as operações de multiplicação e divisão com sucesso.

VERSÃO FLASK PARA EXECUÇÃO LOCAL:
1. pip install -r requirements.txt
2. python app.py
3. Abrir http://127.0.0.1:5000 no próprio computador.

OBSERVAÇÃO:
O site público usa a versão de navegador em docs/index.html.
A versão Flask também permanece disponível no repositório.
